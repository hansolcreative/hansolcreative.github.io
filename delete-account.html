Account Deletion (계정 삭제 안내)

Hansol Creative의 게임 이용 중 생성된 계정 및 관련 데이터 삭제 요청 방법입니다.

Data Deletion Policy

Hansol Creative의 앱(Number Crush, 낱말짝궁 등)은 기본적으로 기기 로컬 저장을 지향하지만, Firebase Auth 등을 통해 계정이 생성된 경우 사용자의 요청에 따라 모든 데이터를 영구적으로 삭제할 수 있습니다.

How to Request Deletion

계정 및 개인정보 삭제를 원하실 경우 아래 정보를 포함하여 이메일로 요청해 주시기 바랍니다.

  • Email: hansolcreative@gmail.com
  • Required Information: 게임 이름, 사용자 UID (게임 설정 화면에서 확인 가능) 또는 가입 시 사용한 이메일 주소

Processing Time

삭제 요청을 받은 후 영업일 기준 7일 이내에 모든 데이터를 파기하며, 파기 완료 후 확인 이메일을 보내드립니다.
